Implemente somente a próxima tarefa pendente da milestone atual.

Antes de alterar código:

1. leia AGENTS.md;
2. consulte ai_handoff.md;
3. leia o arquivo da milestone atual;
4. consulte architecture.md apenas se necessário;
5. leia somente os arquivos de código relacionados à tarefa.

Regras:

- implemente SOMENTE uma tarefa;
- respeite architecture.md;
- não faça refatorações não relacionadas;
- não altere arquitetura sem necessidade;
- não adicione dependências sem necessidade;
- preserve compatibilidade com o código existente;
- não implemente tarefas futuras antecipadamente.

Após implementar:

1. execute os testes relevantes;
2. execute lint/typecheck/build aplicáveis;
3. corrija problemas causados pela implementação;
4. revise o diff;
5. confirme os critérios de aceitação da tarefa;
6. marque a tarefa como concluída no arquivo da milestone.

Ao terminar informe:

TAREFA CONCLUÍDA:
ARQUIVOS ALTERADOS:
TESTES EXECUTADOS:
RESULTADO:
DECISÕES TOMADAS:
PENDÊNCIAS:
PRÓXIMA TAREFA:
