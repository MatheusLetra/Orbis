# M04 — Identidade: empresas, usuários e memberships

## Objetivo
Criar o modelo multiempresa, identidades globais, memberships e perfil funcional de funcionário.

## Dependências
- M02.
- M03.

## Tarefas
1. Criar módulo `companies`.
2. Criar entidade e use cases de empresa.
3. Criar módulo `users`.
4. Criar cadastro de usuário com senha hasheada.
5. Criar `Membership` como vínculo entre usuário e empresa.
6. Validar acesso à empresa.
7. Permitir troca de contexto quando aplicável.
8. Criar cargo no perfil de funcionário.
9. Aplicar isolamento por `company_id`.

## Critérios de aceitação
- Empresa, usuário e membership são persistidos.
- Usuário acessa somente empresas com membership.
- `companyId` é validado no backend.
- Isolamento entre dois tenants é testado.
- Cargo está separado de autorização.

## Decisões existentes
- `Company` é tenant.
- `User` é identidade global.
- `Membership` vincula usuário e empresa.
- Cargos iniciais: `ADMINISTRADOR`, `GESTOR`, `SUPORTE`, `TESTADOR`, `DESENVOLVEDOR`.
- Cargo é atributo funcional de RH, não mecanismo de autorização.
- UX de usuário em múltiplas empresas: **A confirmar**.
- Separação definitiva entre funcionário e usuário: **A confirmar**.
