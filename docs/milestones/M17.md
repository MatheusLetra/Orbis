# M17 — Chat

## Objetivo
Implementar chat interno por tenant, com persistência e tempo real.

## Dependências
- M16 para WebSocket compartilhado.
- M04–M06.

## Tarefas
1. Persistir `Conversation`, `ConversationMember` e `Message`.
2. Isolar conversas por `companyId` e membership.
3. Criar conversa.
4. Listar conversas.
5. Enviar e listar mensagens.
6. Marcar mensagens como lidas.
7. Implementar WebSocket.
8. Usar Redis pub/sub apenas se necessário.
9. Criar endpoints de conversas e mensagens.
10. Criar interface responsiva.

## Critérios de aceitação
- Mensagens são persistidas no PostgreSQL.
- Somente membros autorizados acessam conversas.
- Entrega em tempo real funciona com WebSocket ativo.
- Isolamento tenant é validado.
- Interface funciona em mobile e respeita o tema.
- Testes de isolamento passam.

## Decisões existentes
- PostgreSQL é a fonte de verdade.
- Redis não substitui o banco de mensagens.
- Redis é opcional e pode atuar como pub/sub.
- Chat é interno ao tenant.
