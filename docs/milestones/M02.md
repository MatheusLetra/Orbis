# M02 — Infraestrutura de dados

## Objetivo
Configurar PostgreSQL, Drizzle, migrations versionadas e schema base.

## Dependências
- M01.

## Tarefas
1. Configurar conexão PostgreSQL em `API/src/infrastructure`.
2. Criar `drizzle.config.ts`.
3. Configurar geração e aplicação de migrations.
4. Criar schema base para as tabelas documentadas.
5. Aplicar `company_id`, índices, foreign keys e constraints.
6. Validar migration e health check do banco.

## Critérios de aceitação
- Migration gerada, revisada e aplicada em banco local.
- Conexão validada por query e health check.
- Convenções de tenant e índices compostos aplicadas.
- Migration funciona em banco limpo.

## Decisões existentes
- PostgreSQL é a fonte de verdade.
- Drizzle fica somente na infraestrutura.
- Anexos usam `BYTEA` em `attachment_blobs`.
- Campos e constraints finais devem ser derivados dos use cases.
- Enums provisórios devem ser validados nos módulos correspondentes.

Concluída.
