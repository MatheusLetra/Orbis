# M09 — Tarefas e histórico de status

## Objetivo
Implementar a entidade `Task`, suas transições e o histórico imutável.

## Dependências
- M04–M06.
- M08 opcionalmente.

## Tarefas
1. Criar entidade `Task`.
2. Implementar estados `TODO`, `IN_PROGRESS`, `PAUSED`, `DONE`.
3. Implementar transições de status.
4. Criar `TaskStatusHistory`.
5. Implementar criação, atualização, listagem, consulta e transição.
6. Aplicar permissões `tasks.*`.

## Critérios de aceitação
- Toda mudança de status gera histórico.
- Transições inválidas retornam `BusinessRuleError`.
- Histórico não é editável.
- Permissões são aplicadas.
- Testes cobrem todas as transições.

## Decisões existentes
- Não criar estados adicionais sem necessidade documentada.
- Transições documentadas incluem `TODO → IN_PROGRESS`, `IN_PROGRESS → PAUSED`, `PAUSED → IN_PROGRESS` e `IN_PROGRESS → DONE`.
- Regra `PAUSED → DONE`: **não permitida**.
