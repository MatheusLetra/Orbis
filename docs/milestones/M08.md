# M08 — Requisições

## Objetivo
Implementar CRUD e regras de negócio de `Requisition`.

## Dependências
- M04–M06.
- M07 quando houver vínculo com sistema ou versão.

## Tarefas
1. Criar entidade `Requisition`.
2. Implementar `CreateRequisition`.
3. Implementar `UpdateRequisition`.
4. Implementar `ListRequisitions`.
5. Implementar `GetRequisition`.
6. Implementar `DeleteRequisition`.
7. Criar vínculo de responsáveis/equipe.
8. Implementar prioridades `LOW | MEDIUM | HIGH`.
9. Criar DTOs e mappers.
10. Criar endpoints de requisições.

## Critérios de aceitação
- CRUD completo com autorização `requisitions.*`.
- Isolamento tenant validado.
- `number` funciona como identificador de negócio.
- Entrada é validada.
- Testes de API, filtros, isolamento e permissões passam.

## Decisões existentes
- Requisição é distinta de tarefa.
- Uma requisição pode possuir tarefas.
- Prioridade é regra de domínio; cor pertence à apresentação.
- Anexos pertencem a M10.
