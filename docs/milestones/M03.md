# M03 — Núcleo compartilhado

## Objetivo
Criar configurações, erros, logging, health check e primitivas compartilhadas.

## Dependências
- M01.

## Tarefas
1. Validar variáveis de ambiente com Zod.
2. Criar `.env.example`.
3. Criar erros tipados.
4. Criar tradução de erros para HTTP.
5. Criar logger estruturado com request ID.
6. Criar primitivas de `shared/application` e `shared/domain`.
7. Criar tratamento global de erros no Fastify.

## Critérios de aceitação
- `.env.example` existe em `API/` e `app/`.
- Erros tipados são convertidos corretamente para HTTP.
- Logs contêm request ID.
- Health check responde em degradação quando o banco está indisponível.
- Testes e cobertura atendem aos thresholds documentados.

## Decisões existentes
- Não usar `try/catch` indiscriminadamente.
- Erros internos não expõem stack trace em produção.
- O envelope de erro é `{ error: { code, message, details? } }`.
