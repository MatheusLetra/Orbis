# M06 — Autorização por permissões

## Objetivo
Implementar autorização baseada em permissões explícitas, incluindo política de dashboard.

## Dependências
- M04.
- M05.

## Tarefas
1. Criar lista inicial de permissões.
2. Vincular permissões à membership.
3. Criar resolução de permissões.
4. Criar verificação no nível de use case.
5. Criar política de dashboard por empresa, função e usuário.
6. Permitir gerenciamento do quadro próprio sem alterar o quadro global.
7. Validar autorização no backend.

## Critérios de aceitação
- Use cases protegidos verificam permissões.
- Usuário sem permissão recebe `ForbiddenError`/403.
- Dashboard diferencia escopo da empresa e escopo próprio.
- Testes de precedência e autorização passam.
- Permissões são resolvidas por requisição.

## Decisões existentes
- Autorização é permission-based.
- Cargos podem fornecer presets, mas não substituem permissões.
- Não confiar na UI para autorização.
- Não cachear autorização sem estratégia clara.
- Lista de permissões pode evoluir.
