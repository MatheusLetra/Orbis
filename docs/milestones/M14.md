# M14 — Timeline semanal

## Objetivo
Exibir tarefas posicionadas nos dias úteis da semana.

## Dependências
- M13.
- M09/M11.

## Tarefas
1. Criar `GET /timeline/weekly`.
2. Normalizar tarefas e datas no backend.
3. Criar grid semanal.
4. Posicionar tarefas por data.
5. Diferenciar visualmente tarefas pausadas.
6. Implementar ordenação.
7. Integrar alterações entre Kanban e timeline.
8. Implementar filtros.
9. Aplicar autorização.
10. Adaptar a visualização para mobile.

## Critérios de aceitação
- Datas e previsões são refletidas corretamente.
- Tarefas pausadas são diferenciadas.
- Filtros funcionam.
- Autorização `timeline.manage`/`tasks.read` é aplicada.
- Timeline funciona em mobile.
- Visual respeita tema e design system.

## Decisões existentes
- UI não calcula regra de capacidade.
- Dados devem ser normalizados no backend.
- Mudanças de status no Kanban devem atualizar a timeline.
