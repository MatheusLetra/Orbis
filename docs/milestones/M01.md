# M01 — Fundação dos projetos

## Objetivo
Criar as aplicações independentes `API` e `app`, com base técnica, design system, tema e responsividade inicial.

## Dependências
Nenhuma.

## Tarefas
1. Criar `API/` e `app/`.
2. Configurar Fastify, React, Vite, TypeScript strict, shadcn/ui e Tailwind.
3. Criar `GET /health`.
4. Configurar Scalar, Swagger, Vitest e coverage.
5. Criar scripts de desenvolvimento e build.
6. Criar design system, temas claro/escuro, cor de destaque, densidade e persistência de aparência.
7. Criar shell responsivo mobile-first.
8. Configurar `.gitignore`.

## Critérios de aceitação
- `npm install` funciona nas duas aplicações.
- API responde `GET /health`.
- Scalar está disponível em `/reference`.
- App abre sem erros.
- TypeScript strict está habilitado.
- Shell responsivo em viewport mobile.
- Tema e preferências de aparência são persistidos.
- Builds e cobertura passam.
- Nenhum secret é versionado.

## Decisões existentes
- `API` e `app` permanecem independentes.
- Não criar workspace compartilhado.
- Tema, cores e responsividade pertencem à apresentação.
- Preferências de aparência são preferências do usuário.
- O mecanismo definitivo de persistência por usuário depende do modelo de identidade.

## Status
Concluída.
